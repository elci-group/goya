## Current working-tree update, 24 November 2026

The table below preserves the 19 November base inspection. The current tree
implements `emperor build --desktop cosmic`, a bounded theme reader (64 KiB per
key), build-time theme baking from the exact bytes parsed, shared proportional
placement and inverse pointer mapping, scaled bitmap glyphs, xdg-shell state
reporting, and a COSMIC Wayland window smoke with at least one committed buffer.
The build and qualify
reports identify the installed `cosmic-comp` package separately from a running
process candidate, classify the COSMIC Wayland session, and explicitly mark
native seat input as untested. The separate live run in
`evidence/nebula/neb-001-2026-11-24.json` closes NEB-GAP-01 for the current
dirty tree: the user confirmed a proportionate 640x320 App and repeated Add
presses, and the native Wayland App exited with `count=17 revision=17
presented=19`. The automated scope remains in
`evidence/nebula/build-smoke-2026-11-24.json`. These changes also advance
NEB-GAP-05, 12, 14, 15, and 18. A running compositor version and package match,
live resize evidence, and direct pixel sampling of all baked colours remain
open. `goya-freedesktop` is a stub on this branch, so the old notification and
portal observations below are historical and are not available in this tree.

Identifiers start at NEB-GAP-01 and are local to this file. They are not EMP rows. Where a row bears on an Emperor gap, the EMP row is named; the Emperor ledger is updated by the coordinator, not here.

Measured means a command ran on the qualification host and its output is recorded in a named file. Two kinds of record exist. An evidence record is a JSON file under `evidence/nebula/`. A recorded observation is live output from an `#[ignore]` test, copied into crate documentation. A recorded observation is weaker: it has no source SHA, no toolchain field, and no argument vector. Unmet means the behaviour is absent or only specified. Blocked means a missing machine, backend, admission, or external qualification prevents a pass. Pending NEB-E evidence means stream NEB-E owns the work and has not delivered a record. Presence of a protocol is not behaviour (GY-EMP-001 §4.3). This ledger does not certify a NEB milestone, EMP-M1, or a release.

The qualification host is Pop!_OS 24.04 in a COSMIC Wayland session, `WAYLAND_DISPLAY` `wayland-1`, Xwayland on `:1`, `cosmic-comp` package `0.1~1776708607~24.04~21679f2` (`evidence/nebula/probe-2026-11-19.json`).
