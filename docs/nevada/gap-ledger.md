# Nevada requirement gap ledger

Programme: Nevada (Android TV compiler target), contract
`nevada.androidtv/0.0.1`. Inspection date: 18 November 2026, against
branch `nevada/phase0`. Ledger IDs are local to this file (N0-…). The
owner column is unassigned. "No product loss" means the phase-0 slice
does not advertise the missing behaviour: Nevada admits no scenes and
generates no artefacts, so nothing can be silently lost at the boundary
it actually owns. A reachable excluded feature must stay a compile-time
refusal once admission exists.
