# Maja work packages

Status: proposed, unassigned. Integration owns root manifests, shared contracts and merge decisions. Workers use isolated branches/worktrees, check ownership and seek approval before shared changes. Paths are prospective ownership. Evidence and independent review are required at each gate. For every package, preserve failure evidence and discard or revert only its isolated changes; never revert unrelated work.

| ID and objective | Ownership and dependencies | Fixtures, verification, artifacts and gate; exclusions |
|---|---|---|
| A0: handoff | `docs/maja/contracts/**`, later `crates/maja-semantic/**`; canonical frontend read-only | Compare strict scene, origins and IR for nested IDs, Unicode, interactions and geometry; reject missing IDs and lost properties. Run `cargo test --locked -p goya-lang --offline`; deliver field coverage and version negotiation. Gate: contract approval. No parser fork or shared edits. |
| B0: Frampton | `docs/maja/adr/**`, later `crates/maja-frampton/**`; A0 | Inspect pinned authoritative implementation and browser execution, nodes, properties, events and lifecycle. Missing interface fails closed. Deliver matrix and revised ADR. Gate: verified browser render before M1. No invented API. |
| G0: independent baseline | `tests/maja/**`, reports; A0/B0 | Run exact CI on controlled revision; independently author positive, malformed, Unicode and unsupported fixtures. Deliver machine-readable evidence. Gate: independent review; no implementer self-certification. |
| H0: CLI contracts | `crates/maja/**`, `crates/maja-pack/**`; A0/B0 | Specify typed errors, profiles, hashes and exit codes; unknown profile and missing Frampton fail without application output. Deliver CLI/service contract and tests. Gate: approve shared workspace edits. No implicit network. |
| C1: HTML/CSS | `crates/maja-html/**`, `crates/maja-css/**`; approved A0/B0 | Test text, nested geometry, escaping and unsupported effects; deliver deterministic outputs and viewport evidence. Gate M1: real-browser static view through verified Frampton. No universal absolute positioning. |

Gate M4: no critical/high open findings and mandatory accessibility evidence. No markup-only claim. |
| G1: independent qualification | `tests/maja/**`, reports; C1/D1/E1/F1 | Run real-browser counter and oracle comparison, overflow rollback, reload, console, focus and accessible name; compare repeated builds and tamper integrity; assess browser matrix and performance. Deliver evidence and independent decision. Gates M2/M4. |
| H1: packaging | `crates/maja/**`, `crates/maja-pack/**`; approved contracts | Build twice in isolated directories, compare bytes, detect tampering and serve static output. Record exact versions and separate integrity from qualification. Gate M2/M4. No timestamps or host paths in artifacts. |

M0 precedes implementation against shared contracts. A0, B0, G0 and H0 may investigate concurrently. Other tracks may prepare independent fixtures and contracts but cannot claim gates before prerequisites. M2 additionally requires approved binding and initial-state semantics. M3 requires a complete versioned admission matrix; M4 requires independent browser, security, accessibility, reproducibility and performance evidence; M5 requires release and rollback approval.

For every failure record its ID, owner, contract and source revision, reproduction command, expected and actual result, severity, proposed remedy, verification and status. Do not downgrade a failed gate to advance a package.
