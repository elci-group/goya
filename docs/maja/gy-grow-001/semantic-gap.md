# GY-GROW-001 semantic gap

Evidence ledger for the proposed directive, 2026-11-16. This is not a schema, not an admission change, and not a profile. It records what the current sources admit. It does not supply initial values or bindings.

`goya_lang::handoff::admit` returns a provisional in-process GSSH/1 snapshot. Strict parsing can retain a richer scene than the local web profile admits. It does not resolve bindings or persistence (`crates/goya-lang/src/handoff.rs`). Target admission is separate and fail-closed.

## Dispositions

| Item | Disposition | Evidence |
|---|---|---|
| Static root cell id and text (`maja.web.local.v1`) | ADMITTED | `maja_semantic::admit_local_static` admits only profile `maja.web.local.v1` (`LOCAL_PROFILE`): one root `@cell` (`CellKind::Cell`, empty children, no interactions) with an authored `id` and static `text`. Source entries may be `ontology`, that root `cell`, and root properties named `id` or `text`. `StaticWebIr` stores `semantic_id`, `text`, source digest, and the text origin. U+0000 and carriage return in text, and U+0000, carriage return, newline, or tab in the id, are rejected (`MAJA-E0100`). `docs/maja/standalone-profile.md` states the same limit. The local CLI check/build path calls `admit_local_static` and then `pack::write_static` (`crates/maja/src/lib.rs`). That package is experimental static HTML, CSS, and `manifest.json`. It is not production qualification. |
| Children, buttons, inputs, interactions, effects | REJECTED | `admit_local_static` returns `MAJA-E0100` for every other source entry, for any root child, and for any interaction. Parser entry kinds include `button`, `input`, and `interaction` (`crates/goya-lang/src/parser.rs`); none are on the local allow-list. `local_static_rejects_authored_properties_and_nested_nodes` rejects a nested `@cell` and a root `@button`. Effect references are interaction expressions (`effect.key` in `parse_interaction_atom`); they cannot pass because interactions must be empty. `docs/maja/standalone-profile.md`: other authored properties, children, controls, interactions, and effects are rejected. `docs/maja/admission-matrix.md` still REJECTS hierarchy, static presentation beyond this experiment, button, and input for production web builds. |
| Authored initial state | ABSENT | No admitted field carries it. `StaticWebIr` has id, text, digest, and origin only. `handoff::admit` does not resolve initial state. `docs/maja/contracts/frontend-handoff.md`: authored source does not define the complete initial state required by the counter; SDK caller state is an execution input, not authored UI semantics. `docs/maja/adr-002-browser-native.md`: do not infer omitted initial values. `docs/maja/wave-0.md` and gap M0-02 (`docs/maja/gap-ledger.md`) record the same absence. The production matrix marks “Initial state, input binding and visible state binding” REJECTED until an approved contract exists. That rejection is not a definition of the missing values. |
| State-to-view bindings | ABSENT | Same contract gap: `frontend-handoff.md` (state-to-visible-view binding), ADR-002 (do not infer view bindings), M0-02, and `docs/maja/wave-2.md` (no authored view binding). `emit_checked_increment` tells the caller to supply the mapping from controls to visible state (`crates/maja-runtime/src/lib.rs`). `write_static` emits escaped id and text. It does not bind state to a view. |
| Input-to-action argument bindings | ABSENT | `frontend-handoff.md`: the input-control-to-action-input mapping is not defined. `wave-0.md`: the scene contract does not establish input-to-action bindings. `emit_checked_increment` rejects actions whose `inputs` are non-empty and states that the caller must supply control-to-action mapping. Canonical interaction-to-button trigger checks in `goya_lang` (`validate_bindings` via `compile_d1_interactions`) are not argument bindings and are not admitted by `admit_local_static`. Do not treat a trigger name as an input binding. |
| Browser D1 execution connected to an application | ABSENT | `maja_runtime::emit_checked_increment` can emit one pure checked integer-add function for a shape `set key = state.key + N`. The module documents that it does not own state, bind controls, or admit a web profile. Nothing in the `maja` local path calls it; local build stops at `admit_local_static` and `write_static`. `docs/maja/standalone-profile.md`: the generator is not connected to this profile or an application state owner. `docs/maja/wave-2.md`: there is no generated browser application and no D1 browser runtime. |
| Persistence, network, capabilities | REJECTED | Not introduced by the local profile (`standalone-profile.md`). `admit_local_static` has no persistence, request, or capability output. `write_static` sets `default-src 'none'` and emits no script. `docs/maja/admission-matrix.md` REJECTS D2, effects, network, storage, persistence, navigation, workers, and dynamic imports. `docs/maja/contracts/maja-web-1.md`: network, storage, service workers, remote fetch, navigation, and dynamic imports are denied by default; no persistence is implemented. |
| `maja.web.v1` | REJECTED | Reserved fail-closed profile (`WEB_PROFILE`). `admit_web` accepts that name and always returns `MAJA-E0003` (“web profile is not qualified; no production features are admitted”). Any other name returns `MAJA-E0002`. `WebIr` has no public constructor. The CLI match on `admit_web` still reports emission unavailable and writes no artifact (`crates/maja/src/lib.rs`). `docs/maja/contracts/maja-web-1.md` and `docs/maja/admission-matrix.md`: production features stay REJECTED. |
| Frampton as a mandatory local runtime | REJECTED | `docs/maja/adr-002-browser-native.md` supersedes ADR-001 for standalone web output: Frampton is optional for explicitly remote operations and is not part of local execution. `docs/maja/standalone-profile.md`: no Frampton server is required for the interactive-application work that is still missing. Local admission does not call a Frampton adapter. |

## What this ledger does not open

- `MAJA-WEB-IR/1` is not published. `WEB_IR_CONTRACT` is the string `MAJA-WEB-IR/1-draft` (`crates/maja-semantic/src/lib.rs`). `docs/maja/contracts/maja-web-1.md` reserves `MAJA-WEB-IR/1` and says its concrete schema is not approved. `WebIr` is an uninhabited marker. The experimental pack manifest schema `MAJA-STATIC/1-draft` is not that IR.
- `maja.grow.local.v1` does not widen admission. `maja package grow` writes that name only in `metadata/goya-build.json` around an already admitted `maja.web.local.v1` directory. `maja check` and `maja build` still reject the name with `MAJA-CLI-E0003`. The package copies `index.html`, `app.css`, and `manifest.json` and adds no browser logic, `[runtime]` section, or permissions. It does not admit children, buttons, inputs, interactions, effects, initial state, bindings, persistence, network, or capabilities beyond `admit_local_static`.
- Browser/canonical differential tests for an application are not done. `crates/maja-runtime/tests/browser-differential/tests/browser.rs` compares `emit_checked_increment` with the canonical executor on a synthetic page and caller-built snapshots. Those values are not authored application state. `docs/maja/wave-2.md`: the host-only corpus in `tests/maja/differential` uses the canonical executor on both paths; initial values and inputs are test-provided and are not browser equivalence. `tests/maja/browsers/README.md` lists unmet prerequisites and says its smoke checks are not a Maja build or browser qualification.
- Phase 0 exit, MFI, and ERQ are not met. `docs/maja/wave-0.md` leaves M0 open. `docs/maja/gap-ledger.md` leaves every listed blocker open, including M0-02 (initial state and bindings) and M0-05 (no browser qualification). The Maja documents inspected for this ledger do not record a passing MFI or ERQ. `docs/maja/standalone-profile.md` forbids treating static rendering as Phase 1 completion. `docs/maja/wave-2.md` leaves M2 blocked.
- Do not invent initial values or bindings. The contract is missing. Authority for that refusal is `handoff::admit`, `docs/maja/contracts/frontend-handoff.md`, `docs/maja/adr-002-browser-native.md`, `docs/maja/wave-0.md`, and gap M0-02.
